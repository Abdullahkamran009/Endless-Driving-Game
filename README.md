**Endless Driving Game**

A 3D endless driving game I'm building with Unity and C#. The goal is to create a fun driving experience with smooth car controls, realistic physics, random traffic, and an endless road.

I'm building this project to improve my Unity and C# skills while working on different gameplay systems and getting more hands-on experience with game development.

**Features**
- 3D car movement and physics
- Random traffic spawning
- Collision detection
- Endless road generation
- Distance and high score system
- Multiple cars

**Tech Stack**
- Unity
- C#
- Git & GitHub
